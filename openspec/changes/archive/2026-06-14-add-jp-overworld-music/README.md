# add-jp-overworld-music

Optional JP-1.0 overworld music selection for mirror warps and long overworld
screen transitions.

## Status

**Archived 2026-06-14.** The gameplay toggle is default-off, suppressed during
side-by-side ROM comparison, and has no randomizer placement, save-format,
settings-hash, or `kGeneratorVersion` impact.
